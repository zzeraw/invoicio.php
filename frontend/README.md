# Frontend

## Требования

- Node.js 20+ и npm или Docker/Docker Compose

## Локальный запуск

```bash
cd frontend
npm install
npm run dev
```

Фронтенд будет доступен по адресу http://localhost:5173

## Запуск через Docker Compose

```bash
docker compose up -d frontend
```

Фронтенд будет доступен по адресу http://localhost:5173
