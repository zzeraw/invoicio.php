## Инструкции для Codex

1. Всегда использовать Yoda Style для сравнений.
2. Никогда не возвращать в публичных методах сущности Doctrine.
3. Все обращения к сущностям Doctrine писать в классах-репозиториях. Сущности Doctrine не должны быть разбросаны по коду, они должны быть только в классах-репозиториях.
4. Бандлы AppBundle, AdminBundle, ApiBundle являются "тонкими клиентами". Контроллер должен быть тонким, должны передавать данные в соответствующие сервисы для преобразовании/валидации, сложная бизнес-логика должна делегироваться более "взрослым" бандлам.
5. DTO должны быть иммутабельными.
6. В DTO не должно быть никакой бизнес-логики. Только методы-геттеры. Либо jsonSerialize, если DTO применяет интерфейс JsonSerializable.
